# Family Umbrella ☂️

A light, 2-minute browser game that helps families see why protection matters. Drag the umbrella to catch salary coins, pay the bills that rain down, and grab cover shields early. When life brings a surprise hospital stay, the covers you picked up help keep your family dry.

At the end, players see a Family Protection Score, what each cover did in the game and in real life, an illustrative "protection gap" example, and 5 easy next steps.

**Play:** https://laimeitou1126.github.io/family-umbrella/

## Add your own name and WhatsApp button

Add your name and WhatsApp number (country code, digits only) to the end of the link:

```
https://laimeitou1126.github.io/family-umbrella/?agent=Amanda&wa=60123456789
```

The end screen will then say "Have a friendly chat with Amanda" and show a **WhatsApp Amanda** button with the player's score pre-filled.

## Install on a phone

Open the link, then:
- **Android (Chrome):** menu ⋮ → *Add to Home screen* / *Install app*
- **iPhone (Safari):** Share → *Add to Home Screen*

Once opened, it also works offline.

## Notes

This game is for learning and fun only. All amounts are pretend game money or illustrative examples. They are not a quote, an offer or financial advice, and no real company or product is shown.
